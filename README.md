# Kinopoisk → Kinokino

Расширение добавляет оранжевую кнопку «Смотреть» справа от «Буду смотреть» только на странице фильма Кинопоиска (адрес `/film/ID/`). Переход выполняется только при нажатии этой кнопки.

Она открывает адреса вида:

`https://www.kinopoisk.ru/`

в:

`https://www.kinokino.vip/`

Путь, параметры запроса и фрагмент URL сохраняются.

## Установка в Chrome, Edge, Яндекс Браузер

1. Откройте страницу расширений: `chrome://extensions` (в Яндекс Браузере — `browser://tune/`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».

После установки обновите уже открытую страницу Кинопоиска. Нажатие «Смотреть» откроет Kinokino в этой же вкладке.

## Автоматическое обновление домена

Перед открытием фильма расширение получает актуальный домен со страницы `https://brogiro.cfd/`. Последний успешный домен сохраняется и используется, если источник временно недоступен.
